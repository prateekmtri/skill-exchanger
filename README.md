## 🌟 Overview
 
**Skill Exchanger** is a revolutionary peer-to-peer learning platform that breaks down financial barriers to education. Instead of paying for courses, users trade what they know — a graphic designer learns coding from a developer, who in turn learns photography from a photographer.
 
> 💡 **Our mission:** Knowledge should be free. We connect people based on complementary skills, creating a self-sustaining community where *learning is the only currency*.
 
### Why Skill Exchanger?
 
| Traditional Learning | Skill Exchanger |
|---------------------|-----------------|
| 💸 Expensive courses | 🆓 Completely free |
| 📚 One-way learning | 🤝 Mutual exchange |
| 🏫 Fixed curriculum | 🎯 Personalized sessions |
| 🌐 No community | 👥 Vibrant peer network |

## ✨ Features
 
### 🤝 Smart Skill Matching
- Create profiles listing skills you **teach** and want to **learn**
- Advanced matching algorithm finds users with **complementary expertise**
- **Location-based discovery** to find nearby learning partners
- Filter community members by specific skills or availability
 
### 💬 Real-Time Communication
- **AI-Powered Chatbot** — Instant platform assistance via Groq AI
- **WebSocket Messaging** — Live 1-on-1 chat between matched users
- Seamless conversation flow for coordinating sessions
 
### 👤 Rich Profile System
- Multi-step guided profile creation with smooth onboarding
- Showcase your expertise, learning goals, bio, and availability
- Browse detailed profiles of potential partners
 
### 🎨 Beautiful Interface
- Modern **Next.js 14** frontend with smooth animations
- Fully **responsive** — works flawlessly on all devices
- Clean, professional UI with success stories for inspiration
 
### 🔒 Secure & Scalable
- **JWT-based** authentication system
- RESTful API architecture
- **Dockerized** deployment for consistency

## 🚀 Getting Started
 
### Prerequisites
 
Before you begin, ensure you have the following installed:
 
```bash
Node.js   v18+
MongoDB   v6+
Docker    (optional, recommended)
Git
```
 
You'll also need a **[Groq API Key](https://console.groq.com)** for the AI chatbot.
 
---
 
### ⚡ Method 1: Docker (Recommended)
 
The fastest way to get up and running.
 
**1. Clone the repository**
```bash
git clone https://github.com/prateekmtri/skill-exchanger.git
cd skill-exchanger
```
 
**2. Configure environment variables**
 
Create `backend/.env`:
```env
PORT=5000
MONGODB_URI=mongodb://mongo:27017/skill-exchanger
JWT_SECRET=your_super_secret_jwt_key
GROQ_API_KEY=your_groq_api_key
NODE_ENV=production
```
 
Create `frontend/.env`:
```env
NEXT_PUBLIC_API_URL=http://localhost:5000
NEXT_PUBLIC_SOCKET_URL=http://localhost:5000
```
 
**3. Launch with Docker Compose**
```bash
docker-compose up --build
```
 
**4. Access the app**
 
| Service | URL |
|---------|-----|
| 🌐 Frontend | http://localhost:3000 |
| 🔌 Backend API | http://localhost:5000 |
 
---
 
### 🔨 Method 2: Manual Setup
 
**1. Clone the repository**
```bash
git clone https://github.com/prateekmtri/skill-exchanger.git
cd skill-exchanger
```
 
**2. Setup & run the Backend**
```bash
cd backend
npm install
# Add your .env file (see above)
npm start
```
 
**3. Setup & run the Frontend**
```bash
cd ../frontend
npm install
# Add your .env file (see above)
npm run dev
```
 
> 🟢 The app will be live at **http://localhost:3000**

## 🎯 How It Works
 
```
Step 1 ─── Create Profile ──► Choose skills to teach & learn
    │
Step 2 ─── Explore ──────────► Browse matched community members
    │
Step 3 ─── Connect ──────────► Chat in real-time, plan sessions
    │
Step 4 ─── Learn & Teach ────► Exchange knowledge, grow together
```
 
### Step-by-Step Breakdown
 
**1. 📝 Create Your Profile**
- Sign up with your name, email, and location
- Select skills you can teach from **20+ categories**
- Pick the skills you want to learn
- Add a bio and set your availability
 
**2. 🔍 Discover Learning Partners**
- Browse community members on the Explore page
- Filter by location, skill, or availability
- See who can teach what you want to learn — and needs what you offer
 
**3. 💬 Connect & Learn**
- Start real-time conversations with matched partners
- Coordinate virtual or in-person sessions
- Use the AI chatbot for instant platform help anytime
 
**4. 🌱 Grow Together**
- Build your skill portfolio session by session
- Contribute to a supportive learning community
- Inspire others by sharing your success story
